# 💳 CreditBot — кредитный калькулятор в Telegram

Telegram-бот на Java для расчёта графика погашения кредита.

Проект разработан в рамках учебного проекта от компании «Совкомбанк Технологии».

Бот позволяет пользователю рассчитать аннуитетный или дифференцированный график платежей, просматривать историю расчётов, а менеджеру — анализировать обращения пользователей и фильтровать данные.

---

## 🚀 Возможности

### 👤 Для пользователя

- расчёт кредита по команде `/calculate`;
- ввод суммы кредита;
- ввод срока кредита;
- ввод годовой процентной ставки;
- выбор типа платежа;
- расчёт аннуитетного графика;
- расчёт дифференцированного графика;
- отображение ежемесячных платежей;
- отображение основного долга и процентов;
- отображение остатка задолженности;
- просмотр истории расчётов через `/history`;
- автоматическое разделение длинных графиков на несколько сообщений.

### 👩‍💼 Для менеджера

Вход в режим менеджера выполняется командой:

```text
/manager
```

После успешной авторизации доступны:

- 📊 общая аналитика;
- 💰 фильтрация запросов по диапазону суммы кредита;
- 💳 фильтрация по типу платежа;
- ⭐ определение популярных параметров;
- 🚪 выход из режима менеджера.

Доступ к менеджерской части защищён логином и паролем.

## 💰 Типы платежей

### Аннуитетный

При аннуитетной схеме пользователь вносит примерно одинаковый платёж каждый месяц.

Для расчёта используется формула:

```text
A = P × i × (1 + i)^n / ((1 + i)^n - 1)
```

где:

- `A` — ежемесячный платёж;
- `P` — сумма кредита;
- `i` — месячная процентная ставка;
- `n` — количество месяцев.

### Дифференцированный

При дифференцированной схеме основной долг делится на равные части, а проценты рассчитываются от оставшейся задолженности.

Поэтому размер платежа постепенно уменьшается.

## 🧩 Принципы проектирования

При разработке использовались принципы объектно-ориентированного программирования и разделения ответственности.

### SOLID

Классы имеют отдельные зоны ответственности:

- классы-калькуляторы выполняют расчёты;
- `LoanService` отвечает за бизнес-логику работы с кредитом;
- `AnalyticsService` отвечает за аналитику;
- repository отвечает за хранение запросов;
- Telegram-бот отвечает за взаимодействие с пользователем.

### Factory Pattern

Для выбора алгоритма расчёта используется фабрика:

```java
PaymentCalculatorFactory
```

Она создаёт необходимый калькулятор в зависимости от выбранного типа платежа.

Оба алгоритма реализуют общий интерфейс:

```java
PaymentCalculator
```

Благодаря этому расчёт можно расширять новыми типами платежей без изменения основной бизнес-логики.

Также при разработке учитывались:

- DRY;
- KISS;
- YAGNI;
- Low Coupling;
- High Cohesion.

## 💾 Хранение данных

Для хранения запросов используется:

```java
InMemoryLoanRequestRepository
```

Данные хранятся в оперативной памяти приложения.

Поэтому после перезапуска приложения история расчётов очищается.

Архитектура использует интерфейс:

```java
LoanRequestRepository
```

что позволяет в дальнейшем заменить хранение в памяти на файл или базу данных без изменения основной бизнес-логики.

## 🔐 Безопасность

## ▶️ Запуск проекта

### 1. Требования

Для запуска необходимы:

- JDK 21 или новее;
- Maven;
- Telegram-бот, созданный через BotFather.

### 2. Настройка переменных окружения

Необходимо задать:

```text
BOT_TOKEN=your_bot_token
MANAGER_LOGIN=your_manager_login
MANAGER_PASSWORD=your_manager_password
```

Не добавляйте реальные секретные данные в исходный код.

### 3. Сборка

```bash
mvn clean package
```

### 4. Запуск

Запустите:

```text
ru.creditbot.Main
```

После успешного запуска приложение выведет:

```text
Кредитный бот успешно запущен!
```
